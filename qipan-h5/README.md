# 棋盘财富：H5 联机体验版

这是一个**独立原创的小型地产棋盘联机原型**，用于验证手机浏览器通过同一个 HTTPS 网站直接创建房间、选角色、实时同步、断线重连和统一开局。它不是《大富翁4》的完整移植，不包含原游戏素材、地图、音效与规则引擎。

支持两至四位玩家、24 格棋盘、购买地产、升级、支付租金、随机事件、免租卡、税收和每圈奖金。每局最多 24 轮。每人打开同一网站，房主创建房间，其他人输入房间码加入。大厅全员准备后进入资源就绪检查，所有人确认后同步开局。

## 本地运行

```sh
python -m pip install -r requirements.txt
python server.py
```

访问 http://localhost:10000 。在两个不同浏览器标签页测试时使用不同昵称，并可以用无痕窗口模拟第二位玩家。部署后使用 HTTPS 网址，WebSocket 自动采用 WSS。

## 功能与限制

- 不存储手机号、账户或聊天记录，玩家昵称、随机会话令牌只用于房间临时身份。
- 房间与游戏状态在服务器内存中，不共享到数据库。
- 游戏逻辑由服务器统一裁定，避免客户端各自掷骰导致不同步。
- 因原《大富翁4》素材版权受限，此站点所有图形均为新制作的 CSS 及 Emoji，不含原游戏文件。
- 正式完成同款《大富翁4》移植还需获得合法素材、接入原 GPL-3.0 代码及遵守相应开源授权义务。
